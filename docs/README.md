# Pro Clinic Website

A website for Pro Clinic, a beauty and wellness salon in Gothenburg, enabling clients to discover treatments, learn about the team, and request appointments.

## Features

- **Treatment Directory:** Browse all treatments by category. Each includes description, duration, price and a button to request an appointment.
- **Team Page:** Meet the professionals. Photos and bios build trust and personal connection.
- **Offers & News:** Salon promotions and updates displayed prominently.
- **Booking Requests:** Visitors submit their name, contact details and preferred treatment via a contact form. The salon staff receives notifications.
- **Admin Dashboard:** Password-protected area for salon staff to create and edit treatments, manage offers, and view incoming requests.
- **Search:** Site-wide search to find treatments by name or category.
- **Responsive Design:** Works seamlessly on mobile, tablet and desktop.

## Tech Stack

- **Framework:** Next.js with TypeScript
- **UI Components:** shadcn/ui
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Hosting:** Vercel
- **Repository:** GitHub

## Design Principles

The site conveys professionalism and luxury without coldness. Navigation is intuitive and booking calls-to-action are prominent. The overall impression is of a high-quality, established salon that feels welcoming and trustworthy.
